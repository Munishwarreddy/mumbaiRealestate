# Mumbai Real Estate (Horizon Luxury Living)

This is a modern luxury real estate platform built with Next.js 15, Tailwind CSS, Framer Motion, and Lucide React.

## Features
- **Modern Luxury UI**: Elegant aesthetics with rich micro-animations and responsive design.
- **Interactive Property Showcase**: Filterable property listings with detailed cards and galleries.
- **Agent Profiles**: Dynamic agent directory and individual detail pages.
- **Netlify Ready**: Configured for seamless deployment on Netlify using `@netlify/plugin-nextjs`.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Building for Production

```bash
npm run build
```
